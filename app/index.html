Help / controls

Waypoints: click or drag a visible point; right-click toggles its AI Turbo marker. Add waypoint (+) splits the nearest visible logical route link and resequences following points; Delete waypoint (−) removes the hovered point, repairs incoming links and keeps at least five points per route. Clean route data rebuilds contiguous physical IDs/link displacements and removes only sequence ordinals unused by all three routes, preserving intentional branch gaps/duplicates.

Foreground / Surface: choose a drawing tool, paint value and brush. Curve uses three clicks; Free-form closes near its start point. Right-click uses the secondary paint action.

Recovery: rotate arrows with left/right mouse; Grab group supports multi-cell selection.

Fixed viewport: enable the shared viewport, then drag its bottom-right corner to resize it. The chosen size is retained while switching between the circuit, Backdrop, MiniMap and GeoMap views; use the trackpad or scrollbars to move around larger zoomed content.

Race: drag visible race/pit anchors or edit their fields. Grid X direction is checked against Route A waypoint 3; pit-side and pit-crew placement checks use retail-derived rules. MiniMap and Backdrop use the shared drawing tools (Pencil, Line, shapes, Curve, Free-form and Fill) with pre-made, captured or loaded brushes, including multi-edge and traced captures. Backdrop paints in the verified 32-colour race palette and retains IFF import/remapping; GeoMap has its own edit mode.
